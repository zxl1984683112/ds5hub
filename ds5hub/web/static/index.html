📖 用户指南

📦 一、安装说明

  1. 下载 DS5Hub — 获取最新发布的 ds5hub.exe（单文件，免安装）或解压压缩包。
  2. 首次运行 — 双击 ds5hub.exe，会自动弹出浏览器打开管理面板。
    如使用命令行：python main.py
  3. 安装引导 — 在「设置」页点击「组件检测」，根据提示安装缺失的驱动。
💡 提示：命令行参数
--tray 托盘后台启动 | --web-only 仅 Web | --detect 组件检测退出 | --pack 生成安装脚本

🎯 二、基本使用流程

  1. 配对蓝牙手柄 — 在 Windows 设置中添加 Bluetooth 设备，选择「Wireless Controller」完成配对。
  2. USB 有线连接 — 使用数据线将手柄连接到电脑 USB 口。
  3. 启动 DS5Hub — 程序自动检测已连接的手柄（USB/蓝牙均可识别）。在「手柄管理」页确认列表。
  4. 添加白名单 — 回到仪表盘点击「一键添加白名单」或将 exe 添加到 HidHide 白名单。
  5. 隐藏真实手柄 — 点击对应手柄卡片上的「隐藏」按钮，使系统不再直接读取该手柄。
  6. 客户端连接（本机回环） — 安装 usbipd-win 后，以管理员身份执行：usbip attach -r 127.0.0.1 -b 1-X。Windows 将出现完整功能的虚拟 DualSense（自适应扳机/触觉/灯效全保留），游戏直接识别。

⚙️ 三、HidHide 详细说明

什么是 HidHide？

HidHide 是一个开源 HID 过滤驱动，允许你将指定设备隐藏起来，只让白名单内的应用程序可见。在 DS5Hub 场景中，它确保手柄信号不会被游戏或其他程序抢占。

安装步骤

1. 下载: https://github.com/nefarius/HidHide/releases
2. 以管理员身份运行安装包
3. 重启电脑
4. 使用 DS5Hub 进行后续配置（自动引导）

操作方式

  • 白名单 — 将 DS5Hub 的 exe 路径注册到 HidHide，使其有权限操作隐藏设备。
  • 隐藏设备 — 通过 HidHideCLI 将手柄 GUID 加入隐藏列表，游戏将无法直接检测到它。
  • 取消隐藏 — 在需要调试时可以一键恢复所有设备可见性。
⚠️ 注意：HidHide 需要管理员权限安装和运行。如果安装失败，请右键以"管理员身份运行"。

🧪 四、🎮 手柄测试页使用指南（新增）

切换到顶部导航栏的 「🎮 手柄测试」 标签页即可进入测试界面。这是参考 dualsense-tester 项目编写的内置测试工具。

功能清单

  • 🕹️ 摇杆追踪 — 实时可视化 L/R 摇杆位置（十字准心 + 运动圆点）
  • ⬆️⬇️⬅️➡️ D-Pad — 四方向按键按下高亮显示
  • ⭕△□✕◻ 面键 — 三角/方块/X/圆圈四个按键可视化反馈
  • 🔽 L2 / R2 扳机 — 自适应扳机的按压深度进度条，支持 WebHID 力度反馈
  • 📱 触控板 — 触摸坐标实时显示和触点计数
  • 🌀 IMU 传感器 — 陀螺仪（XYZ 角速度）+ 加速度计（XYZ）实时数值
  • 💫 震动马达 — 发送测试震动脉冲，观察手柄反馈
  • 💡 灯带控制 — 自定义 RGB 颜色发送给手柄灯带，页面预览同步更新
  • 🔋 电池监测 — 电量和充电状态实时更新
  • 📋 输入事件记录 — 所有输入事件的详细时间戳日志，可导出 TXT

两种模式

  • WebHID 模式 — 通过浏览器 WebHID API 直连手柄，可以 读取 AND 写入（震动/灯光等输出）
  • 输入记录模式 — 通过游戏手柄接口读取输入数据，适合简单验证连接
💡 要求：WebHID 功能需要在 Chromium 内核浏览器（Chrome/Edge）中使用，Firefox 需要安装 WebHID 扩展。

💻 五、客户端 attach 用法

主场景：Windows 本机回环（usbipd-win 提供 usbip 客户端 + vhci 驱动）

:: 以管理员身份运行（usbipd-win 安装后自带 usbip.exe）
usbip list -r 127.0.0.1
usbip attach -r 127.0.0.1 -b 1-1

attach 成功后，Windows 设备管理器将出现虚拟 DualSense；Steam / 游戏即可完整识别全部功能（自适应扳机、触觉反馈、灯效）。

扩展：Linux 主机远程 attach

# 列出服务端可用设备（IP 为运行 DS5Hub 的主机）
usbip list -r <DS5Hub主机IP>

# 绑定目标设备（busid 在 Web 面板查看）
sudo modprobe vhci-hcd
usbip attach -r <DS5Hub主机IP> -b 1-1

🔧 六、常见问题排查

Q: 找不到手柄怎么办？

  • 确认手柄已通过蓝牙或 USB 正确连接到电脑。
  • 在 Windows「蓝牙和其他设备」中确认手柄已配对且状态为"已连接"。
  • 尝试拔掉重插（USB 模式）或在设置中重新配对（蓝牙）。

Q: 游戏依然能检测到原始手柄？

  • 确认 HidHide 驱动已经正确安装并处于运行状态（服务名为 NefariusHidHide）。
  • 确认已将游戏的可执行文件 (.exe) 添加到 HidHide 白名单中。
  • 确认已在 DS5Hub 中对目标手柄执行了"隐藏"操作。

Q: Windows 本机 usbip attach 失败？

  • 确认已安装 usbipd-win（提供 usbip.exe 与 vhci 驱动），并以管理员身份执行 attach。
  • 首次 attach 需等待 vhci 驱动加载；若提示驱动异常，重启系统后再试。
  • 确认 DS5Hub 对应手柄端口已监听（手柄卡片显示的端口号）。

Q: Linux 客户端无法连接？

  • 确认防火墙已开放对应的 USB/IP 端口（默认 3240+）。
  • 确认 usbip 版本与服务器端兼容（建议使用 2.0+）。

🗑️ 八、卸载与清除

推荐使用内置一键卸载：设置页 → 危险区 → 「一键卸载 DS5Hub」。它会按安全顺序自动执行：

  1. 解除手柄隐藏 — 第一步必做：若先卸载 HidHide 驱动，真实手柄会从系统消失。
  2. 停止全部服务 — usbip 服务端、自动 attach、重连与托盘。
  3. 移除开机自启 — 清理 HKCU Run 注册表项。
  4. （可选）卸载驱动组件 — 默认保留 HidHide / usbipd-win（其他软件可能依赖）；勾选后经 UAC 确认静默卸载官方 MSI。
  5. 清理配置数据 — 删除 %APPDATA%\DS5Hub\ 与 msi 缓存。
  6. 自删程序 — 退出后自动删除 DS5Hub.exe。

手动兜底路径：仪表盘「取消所有隐藏」→ 托盘退出 → Windows「应用和功能」卸载 HidHide / usbipd-win → 删除 %APPDATA%\DS5Hub\ 与 DS5Hub.exe。
